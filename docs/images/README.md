# Presentation assets

The four dashboard PNGs show actual local research artifacts, captured October 7,
2026. No market response stubs or synthetic success states were used for these
images. See the [demo walkthrough](../demo.md) for captions, limitations, and
capture instructions. [capture-manifest.json](capture-manifest.json) records
viewports, image dimensions, file hashes, and source experiment identity.

`architecture.svg` is a hand-authored vector diagram using the dashboard's color
palette. It has an accessible title/description, local system fonts, and no
external assets or scripts. The [architecture document](../architecture.md)
contains an editable Mermaid representation and explains the exact boundaries.
Keep the SVG and Mermaid consistent when implementation changes.

When updating screenshots, use existing real development evidence and preserve
unavailable results. Inspect every replacement for credentials, reserved prices,
misleading returns, clipped text, and stale/error states. Do not publish raw
archives as part of this screenshot package.
